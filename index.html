질문

정말 48시간 안에 만들어지나요?

원하는 예시 사이트와 이미지가 준비된 경우, 자료를 받은 때부터 48시간 안에 완성본을 보내드립니다. 자료가 없거나 페이지가 많은 경우에는 상담 후 일정을 따로 안내해 드립니다.

Claude AI로 만든다는 건 어떤 의미인가요?

Claude AI를 활용해 디자인과 코드 작업 시간을 크게 줄였습니다. 그래서 일반적인 제작보다 빠르게 완성본을 보여드리고, 수정도 빠르게 반영할 수 있습니다. 구성과 마무리 확인은 사람이 직접 합니다.

완성 후에 수정할 수 있나요?

네. 완성본을 확인하신 뒤 문구, 사진, 색상, 섹션 순서 등 바꾸고 싶은 부분을 알려주시면 반영해서 다시 보내드립니다.

휴대폰에서도 잘 보이나요?

모든 사이트는 휴대폰, 태블릿, PC 화면에 맞춰 배치가 자동으로 바뀌도록 만듭니다. 위 제작 사례를 휴대폰으로 열어 확인해 보세요.

사이트 주소(도메인)와 호스팅은 어떻게 하나요?

제작 사례처럼 카페24 호스팅이나 GitHub Pages로 바로 공개할 수 있습니다. 이미 사용 중인 도메인이 있다면 연결해 드립니다.
